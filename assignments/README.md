# Assignments

Each assignment is published as a pair:

* **`<Name>.pdf`** — the handout students read and print.
* **`<Name>.ipynb`** — the same problems as a starter notebook: given data pre-filled,
  an empty code cell under every task, and an *Interpretation* cell to close each problem.
  Students submit this notebook (renamed `RegNo_<Name>.ipynb`) together with its PDF export.

The deploy workflow copies both files to the site and renders the notebook to a
"Read" page. The card on `index.html` (section `#assignments`) links to all three.

Worked solutions are **not** kept in this public repository.
