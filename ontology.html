Reference ontology

What chemical engineering covers — and where this course fits

This is the School's reference body-of-knowledge for chemical engineering: 16 knowledge areas, grounded in the PEC 2023–2024 accreditation guidelines read alongside AIChE/ABET programme criteria, broken down into knowledge units and topics. It's maintained separately from any one course's syllabus, so it can be used as a yardstick — a map of the discipline, not a description of what's already being taught.

On this site it does two jobs. For a new notebook, it's a place to find a real chemical-engineering topic — a reactor, a distillation column, a heat exchanger — to build a programming example around, instead of reaching for a generic dataset. For students, it's a map back from "why am I learning NumPy in a programming course" to the rest of the curriculum this feeds into.
