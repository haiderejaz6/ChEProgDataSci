Course description

This course provides a practical introduction to programming and data science using Python. Students will gain hands-on experience in programming fundamentals, logic building, and the application of data science tools relevant to chemical engineering. Emphasis is placed on developing competency in using modern software tools for solving problems and analyzing data.

Course contents

01
Introduction to Computers and Python — hardware, software, OS, programming languages, Internet & WWW, software technologies, big data.
02
Python Programming Basics — variables, assignment, arithmetic operators, print function, strings, user input.
03
Programming Logic — flow charts, program structure, logic building, algorithms.
04
Conditional Statements — Boolean operators, if/else, comparison operators, pseudocode, control statements.
05
Repetition Structures — for/while loops, sentinel-controlled iteration, break/continue, nested loops.
06
Functions — defining functions, parameters, return values, default arguments, scope, imports, call stack.
07
Sequences: Lists & Tuples — creation, slicing, passing to functions, sorting/searching, 2D lists.
08
Dictionaries & Sets — creation, methods, comparisons, mathematical operations, comprehensions.
09
NumPy Arrays — creating arrays, attributes, indexing, slicing, reshaping, performance, transposing.
10
Strings — formatting, concatenation, manipulation.
11
Files and Exceptions — reading/writing files, text processing, JSON, pickling, error handling.
